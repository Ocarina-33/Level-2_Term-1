# BookStop: Online Bookstore Management System

## Overview

A comprehensive full-stack e-commerce web application for online bookstore management, developed as part of CSE216 Database Sessional. The system integrates customer-facing features with administrative tools, demonstrating advanced database design and web development practices.

## Technical Architecture

### Technology Stack

**Backend**
* Node.js and Express.js for server-side logic
* PostgreSQL for relational database management
* JWT-based authentication with bcrypt password hashing

**Frontend**
* EJS templating engine
* Bootstrap 5 for responsive design
* JavaScript for client-side interactivity
